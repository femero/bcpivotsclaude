| Conciliación            | Reconciliation     |
| Pago reportado          | ReportedPayment    |
| Movimiento del core     | CoreTransaction    |
| Referencia de operación | OperationReference |
| Monto                   | Amount             |
| Moneda                  | Currency           |
| Diferencia              | AmountDifference   |
| Tolerancia              | Tolerance          |
